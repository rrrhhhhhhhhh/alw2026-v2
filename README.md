Custom HTML/CSS using the original site’s Adobe Caslon typography and header position.

- `index.html`: option 1 — ART / CREATIVE SERVICES.
- `option-2.html`: option 2 — ART / CREATIVE SERVICES / STYLING.
- `creative-services.html`: PDF draft copy, five gray image placeholders.
- ART links to https://andrealongacrewhite.com/ (the current live art website).
- STYLING links to https://www.white-starr.com/ in a new tab.

## Preview
In Settings → Pages, choose Deploy from a branch, main, /(root), then Save. No build step is needed. The second opening option is at option-2.html and the services page is at creative-services.html.

## Before launch
Approve PDF copy, pricing and credits; replace five image placeholders; confirm contact email (taken from the existing website). Unfinished testimonials and Instagram placeholder are omitted. Styling content from the PDF is retained. Remove noindex metadata for the final live site. Original Adobe Fonts configuration is reused; check the test domain is permitted if the font falls back.

Only the opening pages, Creative Services, their styles and favicon are published here. The existing art website remains at its original address.
